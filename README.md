# dropmyfile

A single-page GitHub Pages site that displays a Python MySQL-connector code snippet with syntax-friendly styling.

## Features
- Minimal static page rendering a full Python example (connect, query, fetch, error handling)
- Dark-on-light `pre` block with monospace font and word wrap
- Deployed to GitHub Pages via a `CNAME`

## Tech Stack
- HTML/CSS (inline styles), GitHub Pages

## Project Structure
```
index.html     # page containing the displayed Python code
CNAME          # custom domain for GitHub Pages
```

## Installation
No dependencies — pure static HTML.

## Usage
Open `index.html` in any browser, or push the repo to GitHub Pages (custom domain via `CNAME`).
